# Portfolio Setup & Admin Guide

This is the small setup guide I use for this portfolio when I want to get everything running locally or hand it off cleanly.

## Database Setup (Supabase + Postgres)

### 1. Create the Supabase project
- Create a new project at https://supabase.com
- Open the SQL editor in the Supabase dashboard
- Run the SQL below to create the tables this portfolio expects

### 2. Create the tables
Paste this into the Supabase SQL editor:

```sql
create table if not exists projects (
  id bigint generated by default as identity primary key,
  title text not null,
  summary text not null,
  stack jsonb not null default '[]'::jsonb,
  link text not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists availability (
  id bigint primary key default 1,
  status text not null default 'Open to Commissions',
  updated_at timestamptz not null default now()
);

insert into availability (id, status)
values (1, 'Open to Commissions')
on conflict (id) do nothing;
```

### 3. Add the environment variables
Create a `.env.local` file in the project root and drop in your Supabase values:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

## What this portfolio includes

### Main portfolio page
- Responsive layout for phone, tablet, and desktop
- Animated hero section
- Featured projects section
- Technical skills section
- Footer with contact links

Open it at: `http://localhost:3000`

### Admin dashboard
- Open at: `http://localhost:3000/admin`
- Update your current availability status
- Add, edit, or remove projects

## Managing content

### Add a project
1. Go to `/admin`
2. Fill in the project details
3. Click add project

### Edit or remove a project
1. Find the project in the list
2. Click edit or delete
3. Save your changes

### Update availability
1. Open the admin page
2. Choose the status you want
3. Save it

## Run locally

### Development
```bash
pnpm dev
```

### Production build
```bash
pnpm build
pnpm start
```

## Common issues

### Supabase connection problems
- Make sure the Supabase project is active
- Check that `.env.local` has the right values
- Confirm the tables are created in Supabase

### Port is already in use
- Try a different port if needed
- Or restart the dev server

### Build issues
- Remove `.next` and rebuild if necessary
- Reinstall dependencies if something feels off

## API overview

### Projects
- `GET /api/projects` — list projects
- `POST /api/projects` — create a project
- `PUT /api/projects/[id]` — update a project
- `DELETE /api/projects/[id]` — delete a project

### Availability
- `GET /api/availability` — get the current status
- `PUT /api/availability` — update the status

## Small note on security

The admin area is protected, so keep the admin password and JWT secret secure in production. Use HTTPS and avoid exposing your environment variables.
