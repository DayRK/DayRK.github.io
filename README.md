# Modern Dynamic Portfolio

This is my personal portfolio site — a place to share the work I build, the ideas I’m exploring, and the projects that reflect how I think and create. I built it with Next.js, TypeScript, and Tailwind CSS to keep it fast, clean, and easy to maintain.

## What you’ll find here

- A polished landing page that introduces my work
- A projects section that highlights selected builds
- A simple admin dashboard for updating portfolio content
- Supabase-backed data for projects and availability
- Vercel analytics and performance monitoring

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Getting started

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 to view it locally.
